## About The Project

Linia is a cross-platform task manager that stores tasks as Markdown files with YAML frontmatter, making it compatible with Obsidian workflows. It offers multiple views so you can plan and track work in the format that fits your day.

### Key Features

- **Markdown Tasks**: Tasks are stored as plain Markdown files with YAML frontmatter for easy sync and editing.
- **Multiple Views**: Switch between List, Kanban, and Gantt views.
- **Project Roots**: Manage multiple folders and per-project groupings.
- **Archive Workflow**: Archive tasks without losing history.
- **Cross-Platform**: Runs on Android and desktop (Linux, Windows, macOS).
- **Optional Cloud Sync**: Sync tasks across devices (configure in-app).

## Installation

Download the latest builds from the [Releases Page](https://github.com/Deadbush225/linia/releases).

### Android

1. Download the `.apk` file for your device.
2. Tap the file to install (you may need to allow installation from unknown sources).
3. Open Linia and select your Obsidian project folder.

### Linux

1. Download the `.tar.gz` archive.
2. Extract and run the binary.

## Development

If you want to build the app yourself or contribute:

### Prerequisites

- [Dart SDK](https://dart.dev/get-dart)
- [Flutter SDK](https://flutter.dev/docs/get-started/install)

### Setup

```bash
# Clone the repository
git clone https://github.com/Deadbush225/linia.git

# Navigate to the project directory
cd linia

# Install dependencies
flutter pub get

# Run the app
flutter run
```
