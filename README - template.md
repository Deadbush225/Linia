## About The Project

ePrint is designed to help small printing businesses price their services fairly and keep track of job orders efficiently. By scanning documents, the app can analyze content to suggest pricing, ensuring you get paid for the ink and paper you use.

### Key Features

- **Intelligent Pricing**: Automatically analyzes document color and coverage to suggest fair prices.
- **Batch Scanning**: Scan multiple pages quickly to build a complete order.
- **Automatic Totals**: Instantly calculates the total cost for complex jobs.
- **Offline First**: Works completely without Wi-Fi or internet connection.
- **Lightweight**: Small app size that runs smoothly on most devices.

## Installation

You can download the latest Android APK from the [Releases Page](https://github.com/Deadbush225/PrintRates/releases).

1. Download the `.apk` file to your device.
> For most android the `ePrint-arm64-v8a-release.apk` is enough 
2. Tap the file to install (you may need to allow installation from unknown sources).
3. Open ePrint and start managing your print jobs!

## Development

If you want to build the app yourself or contribute:

### Prerequisites

- [Dart SDK](https://dart.dev/get-dart)
- [Flutter SDK](https://flutter.dev/docs/get-started/install)

### Setup

```bash
# Clone the repository
git clone https://github.com/Deadbush225/PrintRates.git

# Navigate to the project directory
cd ePrint

# Install dependencies
flutter pub get

# Run the app
flutter run
```
